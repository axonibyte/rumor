# Mutants for the planted-lie statute

Each file is `../statute.rego` with ONE clause changed, and the harness
requires each to make at least one case in `../cases/` disagree. A file
identical to the statute is refused naming the cut.

## The one that is deliberately absent

`m2-ignores-knowledge` — cutting `c.ref in input.known`, so every claim is held
whether the observer was told of it or not — **cannot be killed from this
example** and has been removed rather than left to survive. To kill it a case
needs a claim the observer was never told, and the finding for an observation
that agrees with what the observer knows while disagreeing with the whole truth
is exactly the `explained` reading asked about at r1.2/2 and not yet settled.

It belongs to the transitive-count example, whose whole subject is the untold
claim, and it lands there once the reading is settled. Recorded here so the
gap is visible rather than inferred from a shorter directory.
